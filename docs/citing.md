## Releases

A GitHub release publishes the package to PyPI (`.github/workflows/release.yml`), with
build provenance, once anywidget-instruments, on which it depends, is on PyPI itself.
The version of the release, of `pyproject.toml` and of `CITATION.cff` must agree.
